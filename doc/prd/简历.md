# 📄 项目简历描述指南：《旅行家Pro·智慧景区导游》

> **项目简介**：  
> 《旅行家Pro·智慧景区导游》是一款面向 C 端游客与 B 端景区管理方的全栈智慧文旅 AI 导览系统。系统集成了 Live2D/矢量数字人伴游、低延迟 SSE 流式语音对谈、VR3D 即拍即识多模态文物研判、全人群适老/童趣感知识别以及 B 端游客情感雷达与客流预测大屏，旨在打造“千人千面、随问随答”的下一代智慧导览示范工程。

---

## 👨‍💼 岗位一：AI 产品经理 (AI Product Manager)

### 🛠️ 技术栈

> **一句话栈（前端 + 后端 + AI 服务）**：
> `React 19 (Next.js 16 App Router)` + `Node.js (Drizzle ORM · PostgreSQL)` + `阶跃星辰 StepFun / SiliconFlow / DeepSeek 多模态大模型`

- **前端层**：React 19 · Next.js 16 (App Router) · TypeScript 5 · TailwindCSS 4 · Framer Motion 12 · shadcn/ui + Base UI · Live2D Cubism SDK (WebGL) / 自研 SVG 矢量数字人 · Web Speech API · 高德地图 JSAPI · PWA (ServiceWorker)
- **后端层**：Node.js (Next.js Route Handlers) · Drizzle ORM · PostgreSQL · Zod 4 校验 · MCP Server (`@modelcontextprotocol/sdk`) · Vercel Cron 定时任务 · `@eazo/sdk` 会话鉴权 · `@turf/turf` 地理空间计算
- **AI 服务层**：阶跃星辰 StepFun（对话 / 多模态识图 / TTS / ASR）· SiliconFlow（TTS / ASR / Embedding）· 科大讯飞 iFlytek TTS · DeepSeek-V4 大模型 · RAG 向量知识库（余弦相似度 + 关键词混合重排）· SSE 流式响应

### 💡 一句话简介
> 独立主导研发面向 C/B 双端的下一代全栈智慧文旅 AI 导览系统，通过 Live2D 交互数字人、多模态即拍即识与全人群适老感知，打造“千人千面、随问随答”的沉浸式智慧导览示范标杆。
